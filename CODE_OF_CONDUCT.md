# Code of Conduct

This applies to all repositories in the [kaappi GitHub org](https://github.com/kaappi)
and is maintained at
[kaappi/community/CODE_OF_CONDUCT.md](https://github.com/kaappi/community/blob/main/CODE_OF_CONDUCT.md),
the canonical copy. Be respectful and constructive in all interactions.

Instances of abusive, harassing, or otherwise unacceptable behavior may be
reported by opening a GitHub issue or contacting a maintainer directly (see
[kaappi/community/MAINTAINERS.md](https://github.com/kaappi/community/blob/main/MAINTAINERS.md)).
